Ordenamiento Quicksort

Vista previa detallada del desafío antes de sumarlo a tu catálogo.

Enunciado

Implementá el algoritmo de ordenamiento Quicksort para ordenar un arreglo de números enteros de menor a mayor.


Reglas:

  • No podés usar métodos de ordenamiento nativos del lenguaje (ej: Array.prototype.sort()).
  • Debés implementar la lógica de pivote in-place para optimizar el uso de memoria.
  • La complejidad de tiempo promedio debe ser O(n log n).

Entrada: [10, 7, 8, 9, 1, 5]
Salida esperada: [1, 5, 7, 8, 9, 10]

Metadatos

  • Dificultad: Avanzado (+100 XP)
